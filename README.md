# NPI - LM · Portal de herramientas

Página de entrada con acceso directo a las herramientas de campo:

- **Manejo Agronómico** — stock de químicos, historial de manejo y biblioteca de malezas.
- **Plano de Siembra** — diagramación automática de planos de siembra con mapa geoposicionado.
- **Gestor de Lotes** — gestión de aislamientos y lotes.
- **Análisis de Campaña** — (próximamente) dashboard de resultados de campaña.

## Uso

Abrir `index.html` en cualquier navegador, o instalarlo como app (PWA) desde Chrome/Edge. Cada tarjeta lleva directo a la app correspondiente, publicada en su propio repositorio de GitHub Pages.

Este portal no comparte datos ni login entre las apps — cada una mantiene su propia base y su propio acceso.
